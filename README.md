# Meme-Generator

This project is meant for a user to be able to make a meme out of any image and text.
Make sure you have the necessary libraries installed. To do so, you can view all imported libraries in the UI script. Run the script in thonny/vs-studio, etc, and the interactive UI
Will launch if all needed libraries are installed correctly.
