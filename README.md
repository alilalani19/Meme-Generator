# Meme-Generator

This project is meant for a user to be able to make a meme out of any image and text.

First clone this repo locally, and open the final script in your IDE of choice (UI_v9_FINAL.py).
Make sure you have the necessary libraries installed. To do so, you can view all imported libraries in the UI script. Now Run the script in thonny/vs-studio, or your IDE of choice, and the interactive UI
will launch if all needed libraries are installed correctly.
